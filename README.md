# معرض أعمال عبدالله أحمد — المشروع الثاني

موقع عربي من صفحة واحدة يعرض ثلاثة أقسام أعمال: فيديوهين من أعمال صناعة المحتوى، فيديو من حساب يستاهل، ونماذج ويب قيد التطوير بصور توضيحية.

## فتح الموقع

افتح `index.html` داخل المتصفح بعد فك ضغط مجلد المشروع كاملًا، دون فصل مجلد `assets` عن الصفحة.

## ملفات المشروع

- `index.html`: صفحة معرض الأعمال مع ثلاثة مشغلات فيديو HTML5.
- `style.css`: التنسيق المتجاوب.
- `assets/videos/`: نسخ MP4 مضغوطة ومتوافقة مع المتصفح من الفيديوهات التي أرسلتها.
- `assets/posters/`: صور معاينة مستخرجة من الفيديوهات الأصلية.
- `assets/images/ai-web-prototypes.svg`: صورة توضيحية لمشاريع الذكاء الاصطناعي غير المنشورة.

**ملاحظة:** صور مشاريع الويب توضيحية، ولم تُستخدم صور مزعومة للمواقع غير المنشورة. أرقام المشاهدات في الوصف تخص خبرة/حساب صاحب المعرض، وليست ادعاءً بأن هذه المقاطع الثلاثة حققت تلك الأرقام.

## النشر

أنشئ مستودع GitHub عام باسم إنجليزي مثل `my-works-portfolio`، وارفع محتويات المجلد (وليس مجلد المشروع الخارجي وحده) لكي يكون `index.html` في جذر المستودع. ثم اربط مستودع GitHub بخدمة Cloudflare Pages ضمن `Workers & Pages`؛ لا تحتاج إلى أمر Build لموقع HTML/CSS ثابت.

لا ترفع ملفات الفيديو الأصلية الضخمة؛ النسخ المضغوطة في `assets/videos/` كافية للموقع، وهي الأصلح للنشر.
